# TMM Academy App

Official mobile application for TMM Academy LMS (Learning Management System).

## 🚀 Overview
TMM Academy is a modern, full-featured Learning Management System designed to empower learners with comprehensive professional courses, video lessons, interactive quizzes/exams, and certificate generation.

- **Production API:** `https://academy.tmminnovation.com`
- **API Documentation:** `https://academy.tmminnovation.com/api/documentation`

## 🌿 Branching Strategy
- `main`: Production-ready, stable releases.
- `development`: Active feature development, integration, and continuous progress.
